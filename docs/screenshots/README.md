# BumpSnap screenshot specification

This directory is reserved for runtime captures used by the repository landing page.

The application is designed for the Rabbit r1's 240 × 320 viewport, so screenshots should preserve the device aspect ratio rather than stretching the interface into a desktop layout.

Use demo pregnancy dates and demo images only. Do not capture personal photographs or other private information.

## Required images

### `01-home.png`

Primary README image. Show the home screen after setup with:

- current pregnancy week
- trimester label
- due-date summary
- capture and gallery actions

A reminder banner may be visible if it does not obscure the main layout.

### `02-capture.png`

Show the camera/capture screen with the week chip, full-screen preview area and shutter controls visible. Use a neutral demo image or camera placeholder rather than a personal photograph.

### `03-gallery.png`

Show a populated gallery containing several demo weekly entries. This image should make the longitudinal tracking concept clear.

### `04-slideshow.png` - optional

Include only if the slideshow state is visually distinct enough to add information beyond the gallery screenshot.

## Capture standard

- Preserve a 240 × 320 viewport or an exact integer multiple such as 480 × 640.
- Keep application chrome intact.
- Use the same demo state across the screenshot set.
- Do not include browser bookmarks, local paths or unrelated desktop content.
- Do not use real pregnancy photographs in the public repository.

Three images are sufficient for the landing page. A fourth slideshow image is optional.
